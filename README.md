Handmade using [Hugo](https://gohugo.io) and [Tailwind CSS](https://tailwindcss.com)

## Build

    ./scripts/build.sh          # production build into public/
    ./scripts/build.sh serve    # dev server with live reload, drafts visible

The build script downloads pinned versions of Hugo and the Tailwind
standalone CLI into `.tools/` on first run. No Node or npm required.

`scripts/generate-audio.mjs` (post TTS via ElevenLabs) is the one Node tool.
Run `npm install` once before using it.

## Deploy (Cloudflare Pages)

- Build command: `./scripts/build.sh`
- Build output directory: `public`

## RSS

`/feed.xml` is generated by Hugo (`layouts/index.xml`). It includes published
posts and external posts (`data/external_posts.toml`).

## Content

- `content/posts/` - blog posts (markdown, frontmatter: title, date, tags, toc, image, audio, draft)
- `content/tabs/` - guitar tabs
- `data/external_posts.toml` - posts published elsewhere, shown in the writing list and the feed
- Gallery shortcode: wrap normal Markdown images in `{{< gallery >}}` and `{{< /gallery >}}` to render a masonry-style gallery
